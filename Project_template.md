# Шаблон проекта

## Спринт 7: RAG-бот

### Начальная настройка

- Создана и выбрана ветка `rag` для выполнения проектной работы.
- Локальные вспомогательные материалы добавлены в `.gitignore`, чтобы они не попали в GitHub.
- Подготовлен файл отчёта `Project_template.md`; он будет заполняться после каждого логического шага проекта.

### Процесс сдачи

Проект будет сдаваться через pull request из ветки `rag` в основную ветку собственного публичного репозитория на GitHub. В pull request должны попасть все изменения по проектной работе, а ссылка на него будет отправлена на ревью.
